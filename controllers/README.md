# E-Commerce & Invoice API (Backend)

The server-side API built following the MVC architecture.

## Features
• Built with Node.js and Express.js.
• Authentication using JWT and password hashing (Bcrypt).
• Data validation using Joi.
• Database integration with MongoDB and Mongoose.
• Full CRUD operations for invoices and users.

## Technologies Used
• Node.js & Express.js
• MongoDB & Mongoose
• JSON Web Tokens (JWT) & Joi
